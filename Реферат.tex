The goal of the graduate qualification work is to create a convenient and functional web platform that facilitates job searching for job seekers and personnel recruitment for employers, increases the efficiency of interaction between parties and provides a convenient interface for managing resumes, vacancies and responses.

In the process of creating the web platform, key entities were identified: users (job seekers and employers), resumes, vacancies and responses. These entities are implemented through information blocks in the MySQL database. To ensure functionality, modules and classes were developed that support registration, creation and editing of resumes/vacancies, search and response processing. Technologies used include Symfony (PHP) for the server side, Vue.js for the client interface and Nginx as the web server.
